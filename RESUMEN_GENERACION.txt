================================================================================
NOTAS IMPORTANTES
================================================================================

1. ESTRATEGIA INCREMENTAL
   - Empezamos con imágenes pequeñas (64×64)
   - Validamos completamente cada fase
   - Escalamos gradualmente
   - Evitamos acumular errores

2. FORMATO Q8.8 ES CRÍTICO
   - Debe ser idéntico en Python, C++ y hardware
   - 16 bits: 8 enteros + 8 fraccionarios
   - Multiplicación con shift >>8
   - Saturación 0-255

3. VALIDACIÓN BIT-A-BIT
   - Hardware debe coincidir con modelo C++
   - Tolerancia: ±1 píxel por redondeo
   - Criterio: ≥95% match

4. MODELOS DE REFERENCIA OBLIGATORIOS
   - Según especificación del proyecto
   - Python para desarrollo rápido
   - C++ para validación final
   - Hardware debe ser idéntico a C++

5. NO SALTAR FASES
   - Cada fase construye sobre la anterior
   - Validar checkpoint antes de continuar
   - Troubleshooting es más fácil en módulos pequeños
